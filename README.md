# 元火 · 动漫晚会互动台

面向线下动漫主题答题活动的题库协作与舞台控制系统。出题、审题、节目编排、主持控制和 OBS 展示在同一个工作台完成，舞台固定为 3904×672 画布。

React / TypeScript / Fastify / Socket.IO / SQLite。Node.js 24+，上传检查需要 FFmpeg（`ffprobe`）。

> 本公开仓库只包含源码、测试和通用配置，不包含真实活动题库、参与者信息、媒体素材、展示凭证或部署配置。完整数据和运维材料应在独立私有环境中维护。

## 功能

- **题型**：选择、音乐、场景、台词、推理、连线、演猜，以及由出题人描述舞台表现方式的创新题。
- **协作**：草稿隔离、提交审题、留言、修订历史、并发版本检查和回收站。
- **审核**：审题人可录用、退回修改；创新题可标记“待实现”，由管理员完成网站适配后录用。待审和待实现的题目仅作者、审题人与管理员可见。
- **权限**：管理员自动拥有审题人与主持人权限；主持人控制现场，OBS 展示端使用只读凭证。
- **节目单**：冻结题目版本，支持自动插入题型说明、候场、奖品和结算页；题目修改后原位置暂时跳过，重新录用后恢复。
- **舞台**：选项红绿判定、线索/全图分步揭示、连线判定、答案与解析结算、音视频切题停止和 OBS 音频控制。
- **预览**：题目编辑页与详情页提供单题播放模拟，可放大、撤销、候场和逐步揭晓，音视频默认静音。
- **界面**：侧栏可收起为图标栏并记住状态；展开的预览从内容区左边缘开始，窄屏内部横向滚动，不覆盖侧栏。
- **管理**：账号与权限、改名、密码重置、素材引用保护、题目与历史清理、JSON/ZIP 导出和操作记录。

## 本地启动

```sh
npm ci
npm run build
```

首次启动前设置环境变量，至少包括管理员和站点来源：

```sh
ADMIN_USERNAME=admin
ADMIN_PASSWORD=replace-with-a-long-random-password
APP_ORIGIN=http://127.0.0.1:3010
SEED_PROFILE=examples
```

然后执行 `npm start`。默认监听 `127.0.0.1:3010`，数据写入 `runtime`。首次启动会创建管理员；如果本地存在 `seed/questions.json`，会同时导入示例题库。公开仓库不附带题库与素材，因此默认以空题库启动。已有数据库不会因重启而重置密码或题库。不要把管理员初始化变量暴露给客户端。

本地演示也可执行：

```sh
PREVIEW_ADMIN_PASSWORD=replace-with-a-local-password node --import tsx scripts/preview.ts
```

预览管理员用户名为 `preview`，密码由 `PREVIEW_ADMIN_PASSWORD` 提供。演示数据写入 `.local/`，与部署数据隔离。演示账号仅限本机使用，不要用于联网环境。

开发模式执行 `npm run dev`，前端默认使用 `localhost:5173`，并为后端设置初始化管理员变量。

验证：

```sh
npm test
npm run build
```

集成测试使用临时数据库，不访问正式服务。GitHub Actions 在推送和拉取请求时运行测试与构建，不自动部署。

## 出题与协作

1. 注册后进入“我的题目”，选择题型并填写题干、答案与配置。标题为保存必填项，提交时校验完整内容。
2. 素材支持 JPG、PNG、WebP、GIF、MP3、WAV、H.264/AAC MP4。单文件不超过 200 MB，每人总计 2 GB。素材受权限控制，普通上传不支持 SVG 或外链脚本。
3. 选择题支持 2–8 项，连线题支持 2–8 组一一对应；场景题在原图上拖出揭示区域，相同步骤同时显示；推理线索按编辑顺序展示。
4. 台词题可使用已剪辑的提问视频和答案视频，也可在同一视频设置暂停点或消音区间。未设置独立答案视频时，答案开始点控制续播位置。
5. 保存后进入详情提交。草稿只对作者和管理员可见；提交后所有登录用户可查看并留言。审题人可编辑已提交题目、录用或标记待改。删除进入回收站，管理员可恢复。
6. 创新题必须填写“舞台展现说明”，用于说明题目在舞台上的呈现和交互方式。
7. 修改已录用内容会重新进入待审。修改记录可查看历史舞台预览；并发编辑冲突不会静默覆盖他人版本。

## 主持与 OBS

1. 管理员在账号管理中授予主持权限。主持人新建活动，编排已录用题目及开场、说明、候场、奖品和结束页面。
2. 保存节目单会冻结所选题目的版本。之后题库修改不影响活动快照；重新保存节目单会取用当前录用版本并切回候场，现场进行中不要随意编排。
3. 复制 OBS 完整链接并添加浏览器源，宽度 3904、高度 672。链接包含只读展示凭证，只应提供给直播工作人员；需要撤销时重置凭证。
4. 启用“通过 OBS 控制音频”。主持预览始终静音；实际声音只由展示源输出。多个展示端均可能播放声音，请只让一个音频源进入直播混音。
5. 查看展示端连接和媒体就绪状态，并在活动前测试音视频。浏览器阻止自动播放时，在 OBS 浏览器源的交互窗口允许音频播放。
6. 刷新或重连会恢复当前状态，但不重放操作历史。断线会暂停媒体，恢复后由主持人重新播放。服务重启保留当前题和进度，媒体保持暂停。

## 单题预览与界面

- 编辑页和详情页提供“完整播放预览”，可按主持操作模拟选项、线索、全图、连线和结算。
- 预览只保存在当前浏览器，修改题目会重置模拟，不影响正式活动和 OBS。
- 侧栏“收起”后变为图标栏，状态保存在本机浏览器；再次展开可恢复完整导航。
- 展开预览会随侧栏宽度调整，始终从内容区左边缘开始；窄容器中舞台保持可读宽度并横向滚动。

## 管理员数据

“素材与数据”页面显示素材大小、上传人、类型、预览、引用位置、个人用量和磁盘剩余空间。只有完全未被题目、回收站、历史版本或活动快照引用的素材才可以删除；批量清理会逐一复核引用并原子回滚冲突。

管理员可以导出全部题目的 JSON 与 ZIP，范围包含草稿、回收站、留言和历史版本；ZIP 附带引用素材及文件映射。导出不包含账号密码、登录会话或活动展示密钥。完整恢复服务器仍应使用数据库与媒体备份。

账号管理支持改名、重置密码和删除账号。改名保留用户 ID 与内容归属；重置密码会撤销该用户全部会话；删除账号后禁止登录，但仍保留其历史内容用于追溯。内置 `admin` 不可自删、改名或取消管理员权限。

题目修订占用数据库存储，旧发布、镜像和备份占用磁盘，不直接占运行内存。清理旧版本或备份前应列出清单并保留当前版本、上一版本和最新可用备份；不要执行全局 Docker prune。

## 部署与备份概要

正式部署应使用自己的域名、反向代理、TLS 证书和独立数据目录，并将 `.env`、运行数据库、备份和媒体素材放在仓库之外。反向代理需要转发 WebSocket，并允许题目上传所需的请求体大小。

更新前先备份 SQLite 数据库与媒体目录，保留上一发布版本和对应配置。数据库恢复、素材批量删除、旧版本清理和回滚都应单独确认；不要把生产凭证、Cookie 或展示密钥粘贴到公开日志。

部署脚本、反向代理配置、证书和运维文档按环境单独维护，不进入公开仓库。
